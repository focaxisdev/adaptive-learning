## 繁體中文

借期、歸還地點、續借資格。答一題之後，哪兩項還沒有考到？

**1. 讓新 Chat 讀到指令和教材。** 開啟[指令全文（v0.2.0）](https://raw.githubusercontent.com/focaxisdev/adaptive-learning/v0.2.0/docs/PROJECT_INSTRUCTIONS.md)。本機副本在[專案指令](../docs/PROJECT_INSTRUCTIONS.md)。在新 Chat 的同一則訊息附上該檔或貼入全文，再貼下面整段。如果 Chat 讀不到附件，就直接貼全文。在手機上可用程式碼區塊的複製按鈕，一次取得整段。

```text
請用繁體中文。我是第一次值班，要能依下列規則處理工具借還。
使用模考馬拉松，在這個新 Chat 準備第 1 週期。沒有舊題或成績。
以下三行是完整的虛構教材《社區工具借用站 v1》，沒有其他考試範圍。
S1 借期：藍標工具可借 7 天，橘標工具可借 2 天。
S2 歸還：電動工具交給櫃台，手動工具放進還物箱。
S3 續借：沒有人候借時可續借一次；有人候借就不能續借。

請先用 S1、S2、S3 作能力 ID，列出每項要做的判斷與來源行號。
給藍圖一個版本，停下來等我核對並明確開考。
全池三項都可選；每題只考一項，用原創單選情境題。
一題有效作答就結算並回饋。答對得 1 分，答錯得 0 分。
跳過、待答、無效題都不計入分母或涵蓋，只對可見題目避重。
```

**2. 核對藍圖，再開考。** 第一次回覆應有版本與三項能力，每項都能對回上面的一行。此時還沒有題目。資料有誤就請它更正。核對無誤後送出下一句。

```text
我確認剛才展示的藍圖，請開始第 1 週期。
```

**3. 自己答題，核對涵蓋。** 第一題出現時，已測仍是 **0/3**。依題面回覆你選的選項。若這是有效題，結算應把一項能力連到「第 1 週期，第 1 題」，另外兩項列為未測。例如這題只考借期，已測就是 S1，未測是 S2、S3。即使答錯，這項仍有作答紀錄，此時得分是 **0/1**。

**想試換 Chat？** 在步驟 3 作答前，貼「請給我可貼到新 Chat 的同週期完整交接，保留待答題」。把產生的整段文字貼進另一個新 Chat。核對三行教材、藍圖與週期，確認待答題的題號、題幹和選項原樣保留，且未揭答，再回覆你的選項。若結算後想做補強，而交接標示缺少規則，再貼入[針對性補強](../docs/PROJECT_INSTRUCTIONS.md#針對性補強)區塊。

## English

Loan periods, returns and renewals. After one question, which two decisions are still untested?

**1. Give a fresh chat the instructions and the material.** Open the [full instructions (v0.2.0)](https://raw.githubusercontent.com/focaxisdev/adaptive-learning/v0.2.0/docs/PROJECT_INSTRUCTIONS.md) or the [local copy](../docs/PROJECT_INSTRUCTIONS.md). In one message, attach the file or paste its contents, then add the block below. If the chat cannot read the attachment, paste the full text. On mobile, the copy button on each code block copies the whole block.

```text
Reply in English. I'm new at the tool library and want to
handle loans and returns using the rules below.
Set up cycle 1 of the mock-exam marathon in this chat.
There are no previous questions or scores.
The complete fictional source is Community Tool Library v1:
S1 Loan period: blue tags allow 7 days, orange tags 2 days.
S2 Returns: power tools go to the counter, hand tools
   to the return bin.
S3 Renewal: if no one is waiting, a loan can be renewed
   once. If anyone is waiting, it cannot be renewed.

Use S1, S2 and S3 as skill IDs. For each, show the decision
and the source line. Give the blueprint a version, then
wait for me to review it and explicitly start the cycle.
Keep all three skills eligible. Each original multiple-choice
scenario should test just one skill and have one right answer.
End the cycle and give feedback after one valid answer.
Score 1 for correct, 0 for incorrect. Exclude skipped,
pending and invalid questions from the denominator and
coverage. Check for repeats against visible questions only.
```

**2. Check the blueprint and start the cycle.** The first reply should give a version and three skills, each traceable to a source line. It should pause before posing a question. Ask for a correction if needed. Once it matches, send this message.

```text
I confirm the blueprint you just showed me. Start cycle 1.
```

**3. Answer and check coverage.** With the first question pending, coverage is still **0/3**. Reply with your choice. Once the answer is graded as valid, the report should link one skill to cycle 1, question 1, and list the other two as untested. For example, if the question only tests the loan period, S1 is tested and S2 and S3 remain untested. A wrong answer scores **0/1** and still gives evidence that S1 was tested in this example.

**Want to try a handoff?** Before answering in step 3, send “Give me a complete handoff for this cycle, including the pending question, that I can paste into a fresh chat.” Copy the whole handoff into a new chat. Check the three source rules, blueprint and cycle. The question number, wording and choices should match, with the answer still hidden. Then reply with your choice. If you later choose targeted practice and the handoff says its rules are missing, paste the [targeted practice section](../docs/PROJECT_INSTRUCTIONS.md#針對性補強).

## 日本語

貸出期間、返却場所、延長の可否。1 問解いたあと、まだ出題されていないのはどの 2 項目でしょうか。

**1. 新しいチャットに指示書と教材を渡します。** [指示書の全文（v0.2.0）](https://raw.githubusercontent.com/focaxisdev/adaptive-learning/v0.2.0/docs/PROJECT_INSTRUCTIONS.md)または[ローカルのファイル](../docs/PROJECT_INSTRUCTIONS.md)を開きます。新しいチャットの最初のメッセージにファイルを添付するか全文を貼り付け、続けて以下の文章を貼り付けて送信します。チャットが添付を読めなければ、指示書の全文を貼り付けてください。スマートフォンでは、コードブロックのコピーボタンで全文をコピーできます。

```text
日本語でお願いします。工具貸出所で初めて当番をします。
以下の規則に沿って、貸出と返却の手続きができるようになりたいです。
このチャットで模試マラソンの第 1 サイクルを準備してください。
過去の問題や成績はありません。
架空の教材『地域の工具貸出所 v1』の範囲は以下の 3 項目です。
S1 貸出期間：青い札の工具は 7 日間、オレンジの札は 2 日間。
S2 返却場所：電動工具はカウンターへ、手動工具は返却箱へ。
S3 延長：予約待ちの人がいなければ 1 回だけ延長できます。
   待っている人がいれば延長できません。

S1、S2、S3 を能力 ID にして、それぞれで判断することと
根拠となる教材の行を示してください。設計図に版を付け、
私が確認して開始を指示するまで待ってください。
全 3 項目を出題候補に残し、1 問で扱う項目は 1 つとします。
場面を示すオリジナルの単一選択問題にしてください。
有効な回答 1 件で終了し、結果を返してください。
正答は 1 点、誤答は 0 点。スキップ、未回答、無効の問題は
分母と出題済みの項目に含めません。重複は見える履歴で確認します。
```

**2. 設計図を確認してから開始します。** 最初の返答で版と 3 項目を確認し、それぞれの出典をたどってください。この段階ではまだ出題されません。ずれがあれば修正を依頼し、確認できたら次の文を送ります。

```text
今示された設計図を確認しました。第 1 サイクルを開始してください。
```

**3. 自分で答えて、どの項目がテスト済みか確認します。** 1 問目が未回答なら、テスト済みは **0/3** です。自分で選んだ選択肢を返してください。有効な回答として採点されると、1 項目が「第 1 サイクル・第 1 問」にひも付き、残り 2 項目は未出題のままです。たとえば貸出期間だけを問われたら、S1 はテスト済みで、S2 と S3 は未出題です。この例で誤答した場合も S1 には回答の記録が残り、得点は **0/1** です。

**引き継ぎも試すには。** 手順 3 で答える前に「未回答の問題を含め、このサイクルを新しいチャットに引き継げる完全な引き継ぎ文を出してください」と頼みます。その全文を新しいチャットに貼り付け、3 項目の原文、設計図、サイクルを確認します。問題番号、問題文、選択肢が元のまま表示され、正解が伏せられた状態で、自分の選択肢を返してください。採点後に補習を希望し、引き継ぎ文に規則の不足が示された場合は、[補習の指示](../docs/PROJECT_INSTRUCTIONS.md#針對性補強)も貼り付けてください。
