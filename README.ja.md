# Adaptive Learning

[繁體中文](README.md) · [English](README.en.md) · **日本語**

対話を通じて、さまざまな分野を学ぶためのフレームワークです。問題数を増やすことではなく、学んだことを自力で使えるようになることを目指します。

**v0.2.0 · [MIT License](LICENSE) · [リリース履歴](https://github.com/focaxisdev/adaptive-learning/releases)**

**貸出ルールは3つ、問題は1問。出題されなかった2つはどれでしょう？**

[工具の貸出ルールで模試を1問解いてみる](examples/first-try.md#日本語)。新しいチャットにプロジェクト指示の全文とサンプル教材を貼ります。出題範囲の一覧を確認してから、開始を指示してください。解答後、残りの2つが未出題として挙がっているか、教材と照らし合わせてみましょう。

## はじめ方

1. 新しいチャットで、[プロジェクト指示](docs/PROJECT_INSTRUCTIONS.md)の**全文**と、利用する権利のある教材を AI に渡します。指示の原文は繁体字中国語ですが、学習時の応答は日本語に指定できます。リンクを貼るだけでは、AI が内容を読めるとは限りません。
2. 「＿＿を学んで、＿＿ができるようになりたいです。まずは日本語で通常学習を始めてください。設定に迷うところは、簡単な初期案を提案してください」と伝えます。
3. 目標、使える資料、現在の理解度、時間などの条件を確認したら、そのチャットで最初の短い確認問題に答えます。プロジェクトを設定するときは「コピーできる指示の全文をください」、チャットを移るときは「今の進捗を引き継ぎたいです」と伝えます。

教材がない場合も、学習範囲の限界を確認し、同意したうえで一般知識の練習を始められます。通常のチャットだけで利用でき、インストール、データベース、有料 API は不要です。

| やりたいこと | モード |
| --- | --- |
| 基礎から順に力をつける | 通常学習（既定） |
| 特定のつまずきを解消する | 終了条件を決めた補習。終えたら元の学習に戻る |
| 一回限りの小テストを受ける | 得点・出題記録を引き継がず、次回との重複チェックも不要なら、範囲と採点方法を決めて開始できる |
| 模試を複数回続ける | 知識・技能の一覧（ブループリント）を作成または読み込み、版を確認してから開始を指示する |

小テストの途中で移る場合、引き継ぎ文には進捗と未回答の問題に加えて、転載できる範囲で出題・採点に必要な教材の原文を含めます。原文が足りないときは、引き継ぎ文に示された箇所を新しいチャットに貼ってください。

## 模試マラソンの開始と再開

まず、読める教材の全章から技能を拾い、範囲内の例題・過去問で問われる技能も加えます。各項目の出典、版、該当箇所、未確認の部分を確認してください。正式な試験に合わせる場合は、読める公式問題で難易度も確認します。準備ができたら「この版の範囲を確認しました。新しい回を開始してください」と伝えます。版を確認しただけなら、第1問を出す前に待機します。通常学習や個別の補習には、この準備は不要です。

各章から幅広く出題し、確認した範囲は全体を候補に残します。有効な問題が10問に達するごとに、どの技能をどの問題で扱ったか確認し、終了時には未出題の技能を示します。出題歴だけでは習熟度は判断できず、限られた問題数で全範囲を扱えるとも限りません。類題の判別には、見えている過去の問題と、解答に必要だった判断の要約を別に使います。

選択式の問題を出す前に、採点済みの有効な問題で正答位置が周期的に繰り返されていないか確認します。同じ試験を別のチャットで続けるときは、確認できた直近の位置と履歴の欠落を引き継ぎます。

同じ回の途中でチャットを移るときは、引き継ぎ文を貼り付けます。未回答の問題があれば、元の問題番号と得点を保ったまま、そこで回答を待ちます。終了時には、補習用と次回の模試用に、それぞれ単独で使える引き継ぎ文を受け取れます。

## 学習データの扱い

AI が使えるのは、実際に読める資料と履歴だけです。チャット間で進捗が自動保存・同期されるわけではありません。別のチャットに移るときは、引き継ぎ用の情報を作ってもらい、自分で持ち運びます。非公開教材、実際の解答や点数、会話リンク、認証情報はリポジトリに投稿しないでください。

[設計資料](docs/LEARNING_DESIGN.md)、[検証範囲](docs/VALIDATION.md)、[ライセンスと出典](NOTICE.md)は現在、繁体字中国語で提供しています。例には合成データを使用しています。構造のチェックや合成ケースの検証は、実際の学習効果を示すものではありません。
