# Adaptive Learning

**繁體中文** · [English](README.en.md) · [日本語](README.ja.md)

一套以對話運作、可配置不同學科的學習架構：學習 → 評量 → 診斷 → 有限補強 → 驗證 → 人工交接。目標是能獨立應用，不是累積題數。

**v0.2.0 · [MIT License](LICENSE) · [發行紀錄](https://github.com/focaxisdev/adaptive-learning/releases)**

## 開始

1. 在新 Chat 提供 [專案指令](docs/PROJECT_INSTRUCTIONS.md) 的完整內容，以及有權使用的教材；只貼連結不代表內容可讀。
2. 貼上：「我想學＿＿，希望能＿＿。請先用一般教學開始；我不確定的設定請給簡短建議。」不必先設定考試或補強模式。
3. 確認目標、來源、程度與限制後，直接在這個 Chat 做第一道短診斷。若要另設專案或換 Chat，請說「給我可複製的完整配置」或「請交接目前進度」。

沒有教材時，可先同意標明限制的通用知識練習。無需安裝程式、Work、Library、付費 API、外部台帳或資料庫。程式只在學習目標需要時出現。

| 想做什麼 | 使用模式 |
| --- | --- |
| 建立能力、循序練習 | 一般教學（預設） |
| 釐清特定困難 | 針對性補強；有停止界線，保留回主線位置 |
| 只做一次短測 | 純 Chat 短測，若成績與涵蓋不跨次累計、也不要求跨次避重，可直接約定範圍與計分 |
| 連續進行多個模考週期 | 模考馬拉松，先建或載入知識／能力藍圖，確認後明確開考 |

短測中途換 Chat 時，交接會列出進度與待答題，附上有權攜帶的必要教材原句。若缺少核題所需的原文，依交接標示補貼。

模式由你決定；只把共用規則及已啟用模式放入你的指令。切換到尚未配置的模式時再補必要設定，不把任何證照或題數當跨學科預設。

## 開始或接續模考馬拉松

1. 提供可讀的完整章節與範圍內樣題／歷題，或貼上已有的藍圖。可說「請先列出各章能考的能力、來源版本與位置，再讓我確認」。章節獨有的能力也要列入，缺頁或未讀處標為未知。正式考試的難度另用可讀官方題校準。
2. 核對整份範圍後，明確說「我確認這版藍圖，開始新週期」。只確認版本會停在開考前。每題從確認範圍選取，兼顧跨章混合。每十道有效題可看到近期與累計涵蓋，結算列出未測項。有限題數可能無法走完所有能力，已測也不能單憑題數判為掌握。
3. 同一週期換 Chat，直接貼上交接。有待答題就從原題等待作答，保留題號與成績。結算時取得兩份獨立文字，可選「補強」或在新 Chat 貼「新考」再明確開考。覆蓋紀錄按能力與有效題追蹤，避重另用可見舊題及必要判斷的摘要，歷史不全時可能遇到重複題。

單選題還會核對已判有效題的答案位置，避免近期出現固定循環。換 Chat 時會帶入可核的近期位置；缺史會標明。

## 邊界與維護

來源、歷史與結果只認當前可見證據；不自動保存、讀取其他對話或同步專案。交接由本人保管，**不要把真實答案、分數、私人教材、email、對話連結或憑證提交到 repo**。範例與驗證一律用合成資料。

- [學習設計](docs/LEARNING_DESIGN.md)：維護者理解架構及模式邊界；不是新手必讀。
- [驗證紀錄](docs/VALIDATION.md)：靜態、人工案例、模型互動與真人成效分層，不把規則存在當效果已證。
- [授權範圍與來源歸屬](NOTICE.md)：第三方內容排除及初始快照來源。

需要的核心能力已集中在指令入口；驗收紀錄、舊版本與備份不作執行規則。
