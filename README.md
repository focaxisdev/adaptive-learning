# Adaptive Learning

**繁體中文** · [English](README.en.md) · [日本語](README.ja.md)

一套以對話運作、可配置不同學科的學習架構：學習 → 評量 → 診斷 → 有限補強 → 驗證 → 人工交接。目標是能獨立應用，不是累積題數。

**v0.1.0 · [MIT License](LICENSE)**。這是第一個正式發行版，適合小範圍試用；不保證學習成效、零重複或正式考試代表性。

## 開始

1. 在新 Chat 提供 [專案指令](docs/PROJECT_INSTRUCTIONS.md) 的完整內容，以及有權使用的教材；只貼連結不代表內容可讀。
2. 貼上：「我想學＿＿，希望能＿＿。請先用一般教學開始；我不確定的設定請給簡短建議。」不必先設定考試或補強模式。
3. AI 只確認目前需要的目標、來源、程度與限制，產生自含指令；你可手動貼入專案指令或新 Chat 開頭，再說「開始」。每次只做一題，換 Chat 時自行攜帶交接。

沒有教材時，可先同意標明限制的通用知識練習。無需安裝程式、Work、Library、付費 API、外部台帳或資料庫。程式只在學習目標需要時出現。

| 想做什麼 | 使用模式 |
| --- | --- |
| 建立能力、循序練習 | 一般教學（預設） |
| 釐清特定困難 | 針對性補強；有停止界線，保留回主線位置 |
| 按約定範圍測驗 | 純 Chat 模考；啟用時才設定計分與週期 |

模式由你決定；只把共用規則及已啟用模式放入你的指令。切換到尚未配置的模式時再補必要設定，不把任何證照或題數當跨學科預設。

## 邊界與維護

來源、歷史與結果只認當前可見證據；不自動保存、讀取其他對話或同步專案。交接由本人保管，**不要把真實答案、分數、私人教材、email、對話連結或憑證提交到 repo**。範例與驗證一律用合成資料。

- [學習設計](docs/LEARNING_DESIGN.md)：維護者理解架構及模式邊界；不是新手必讀。
- [驗證紀錄](docs/VALIDATION.md)：靜態、人工案例、模型互動與真人成效分層，不把規則存在當效果已證。
- [授權範圍與來源歸屬](NOTICE.md)：第三方內容排除及初始快照來源。

需要的核心能力已集中在指令入口；驗收紀錄、舊版本與備份不作執行規則。
