# 學習設計與維護邊界

[README](../README.md)是使用者入口；[專案指令](PROJECT_INSTRUCTIONS.md)是唯一可執行行為來源。本文件解釋設計，不另產生一套教學契約。使用者只需提供指令入口及合法教材，不用讀驗收、歷史或備份。

## 最小架構

共同核心處理來源誠實、一次一題、題目品質、證據與人工交接；只有已選模式進入生成指令。一般教學不必先決定考試題數或及格線，非考試目標不套 iPAS。切換未配置模式時再補設定／完整規則，缺規則就索取可讀區塊，不靠不可見記憶。

| 階段 | 可見輸入／輸出 | 何時前進或停止 |
| --- | --- | --- |
| 學習 | 目標、短診斷、簡短主線、說明與一題練習 | 收到回答再前進；保留主線位置 |
| 評量 | 完整任務、實際回答／作品與提示條件 | 正確性、負荷與理解證據分開 |
| 診斷 | 具體錯誤或理由缺口 | 形成可驗假設；跳過／猜答不是確診 |
| 有限補強 | 一個必要焦點、成功條件、返回點；一輪說明＋新結構檢核的回答 | 達標返回；預設兩輪或更短約定時間即停，未解暫存，不自動重置 |
| 驗證 | 新判斷條件、較晚無提示任務 | 即時達標可回主線；延後未做仍待辦 |
| 換對話 | 自足規則／來源狀態、主線／輪數、必要證據、待答全文、不帶未答答案 | 先核來源與狀態，有待答恢復等待；無待答才續原位置 |

未解缺口若阻擋主線，不能假裝通過；暫停該步，給較小先備或不依賴該缺口的下一步供選。沒有返回主線時先確認下一目標。這是停止與恢復契約，不是禁止深入；深入需使用者另約新段落，不能在背景無限加深。此架構不會自動修改既有學習對話。

## 三模式與評量界線

一般教學可依證據調整順序和局部補解；針對性補強只處理選定焦點；模考按既定全池／評分／週期運作，答錯不自動補課、弱點不回灌考試分布。正式分與理由診斷分開，未測不等於不會，示範不等於學員實作。

所有模式都拒收換皮，但不永久禁止同方法；新診斷證據可來自決策條件或誤解辨識，無需增加推理層數。每題預設一核心及必要輔助，正確性不等於負荷適切。正式模考加用實際可讀官方錨點與每 10 題近期／累計檢查；一般學習不捏造官方代表性。詳見指令中的對應模組。

模考沿用同週期不重開、待答不洩答、逐項核對、有效分母及跨週期雙交接。iPAS 中級既有科目 1／3、50 題有效計分是特定配置的保留要求，不是跨領域預設。補強不是下週期開考前提；新週期只在使用者選擇的新 Chat 開始。

## 簡潔與可重用

- 架構與個人資料分離：repo 只有規則、合成測試和去個人化驗證；真實學習進度留在使用者對話／交接。
- 不需要 runtime、外部台帳、去重庫或同步服務。靜態藍圖可選且唯讀；Library 不是依賴。
- 指令自含所以允許必要規則在交接中出現；不要求使用者先閱讀維護者驗收紀錄。只帶已啟用規則與續接必要證據，不搬無限歷史。
- 簡短不等於刪除來源限制、計分保全或等待點。新模式可按需加入，既有模式的有效狀態不能被模板重設。

## 驗收與停止維護

[驗證紀錄](VALIDATION.md)分清靜態檢查、人工合成案例、實際模型互動及真人成效。只有來源可讀與文件規則通過，不能宣稱模型每輪會遵守或學習有效。授權範圍見 [NOTICE](../NOTICE.md)；驗證通過不代表真人學習成效已證。

維護採「設定可觀察驗收→小幅修改→測試→獨立審查→只修缺陷→核對」。沒有已知內容／入口／驗收阻斷時停止修正；兩輪無改善則保留缺陷與續作摘要，不無限美化。
