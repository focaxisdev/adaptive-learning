# 學習設計與維護邊界

[README](../README.md)是使用者入口；[專案指令](PROJECT_INSTRUCTIONS.md)是唯一可執行行為來源。本文件解釋設計，不另產生一套教學契約。使用者只需提供指令入口及合法教材，不用讀驗收、歷史或備份。

## 最小架構

共同核心處理來源誠實、一次一題、題目品質、證據與人工交接；只有已選模式進入生成指令。一般教學不必先決定考試題數或及格線，非考試目標不套 iPAS。切換未配置模式時再補設定／完整規則，缺規則就索取可讀區塊，不靠不可見記憶。

| 階段 | 可見輸入／輸出 | 何時前進或停止 |
| --- | --- | --- |
| 學習 | 目標、短診斷、簡短主線、說明與一題練習 | 收到回答再前進；保留主線位置 |
| 評量 | 完整任務、實際回答／作品與提示條件 | 正確性、負荷與理解證據分開 |
| 診斷 | 具體錯誤或理由缺口 | 形成可驗假設；跳過／猜答不是確診 |
| 有限補強 | 一個必要焦點、成功條件、返回點；一輪說明＋新結構檢核的回答 | 達標返回；預設兩輪或更短約定時間即停，未解暫存，不自動重置 |
| 驗證 | 新判斷條件、較晚無提示任務 | 即時達標可回主線；延後未做仍待辦 |
| 換對話 | 自足規則／來源狀態、主線／輪數、必要證據、待答全文、不帶未答答案 | 先核來源與狀態，有待答恢復等待；無待答才續原位置 |

未解缺口若阻擋主線，不能假裝通過；暫停該步，給較小先備或不依賴該缺口的下一步供選。沒有返回主線時先確認下一目標。這是停止與恢復契約，不是禁止深入；深入需使用者另約新段落，不能在背景無限加深。此架構不會自動修改既有學習對話。

## 三模式與評量界線

一般教學可依證據調整順序和局部補解；針對性補強只處理選定焦點；模考按既定全池／評分／週期運作，答錯不自動補課、弱點不回灌考試分布。正式分與理由診斷分開，未測不等於不會，示範不等於學員實作。

所有模式都拒收換皮，但不永久禁止同方法；新診斷證據可來自決策條件或誤解辨識，無需增加推理層數。審查模考候選時遮住關鍵材料，再讀題幹及選項。如果仍能僅憑措辭選對，先重寫。已核分版本事後判無效時保留原答與原判，再按原計分規準列出有效分母及能力參照的更正。每題預設一核心及必要輔助，正確性不等於負荷適切。正式模考加用實際可讀官方錨點與每 10 題近期／累計檢查；一般學習不捏造官方代表性。詳見指令中的對應模組。

即使四個位置出現次數接近，知道前題答案的學員仍可能從重複排列推測下一題。模考先定內容再安排選項，依最長 6 題的短週期逐題檢查。最長檢查需 18 個位置，因此同週期交接帶最近 17 個可核位置，就能和下一個候選合併檢查。覆蓋、避重、解答正確性各依原證據判斷。

一次性的短測可自行約定範圍與計分。若要求跨週期追蹤成績、累計涵蓋或持續避重，即使每回只有幾題，也採馬拉松流程。一般教學與獨立補強可直接開始。iPAS 中級既有科目 1／3、50 道有效計分題是該配置的要求。

## 馬拉松的範圍、題史與續接

建藍圖時，逐章列出完整官方教材的可觀察能力，再加入範圍內樣題／歷題顯示的能力。每項保留穩定的能力 ID、來源版本、可定位的章節或題號與可讀狀態。未取得的頁面或題面列為未知，不能以連結補足。正式題的另一個用途是估計先備、閱讀量及必要推理的負荷。命題時另選材料與判斷，不沿用官方題幹。

使用者可建立或載入藍圖，核對範圍與限制後確認版本，再明確開始新週期。確認過的範圍在週期內固定。以下兩種紀錄可直接隨交接文字貼入普通 Chat。

| 紀錄要回答的問題 | 保留哪些證據 |
| --- | --- |
| 哪些能力已經測到？ | 以能力 ID 對應週期、有效題號。待答或撤題保留狀態，不列已測。每十道有效題核對最近十題及累計涵蓋，期末區分已測、未測及因缺資料而未知。掌握程度另看實際作答、理由與提示條件。 |
| 候選題的必要判斷做過了嗎？ | 對照可見的原題，並分列舊題的核心能力、不可省略的推理／決策和材料。相近時才索取相關題面，交接不足要標明比對界線。 |

抽選時保留全範圍並跨章混合，已測小節仍可再抽。同一能力可換必要判斷重測。弱點與補強結果留作教學證據，不改候選池。有限題數、未讀來源與缺失題史都要反映在結果中，不硬湊配額或保證不重複。

**合成示例：校園聲景調查（地理與統計）。** 假設教材甲版第 1 章教讀等值線圖，樣題只考第 2 章的超過音量門檻時數占比。藍圖仍收錄「依等值線定位區域」（G1，第 1 章）及「判斷不同時段的觀測能否合併」（S1，第 2 章、樣題 1）。假如附錄只有標題，就記「內容未知」。某回有效題 3 給出各時段超過門檻的比例，測 S1 時須判斷各時段長度是否相等，才能決定能否直接平均。換成車站、改數字或把表格畫成圖，若仍只需同一權重判斷，就拒收。另一題可給出等長但部分重疊的觀測時段，請學員判斷能否直接合併，核心轉為辨識是否重複計入。若這回只有題 3 有效，覆蓋紀錄就是 S1 對應題 3、G1 未測；兩者的掌握程度仍需作答證據。

舊週期遷移時保留題號、分數、分母與原計分設定。有待答先恢復原題等待，不揭答案；缺的題面、藍圖或歷史要標明並在續接時補核。週期結束後分別產生可獨立貼用的補強交接與新考交接。新考版沿用已確認全池，把既有題史帶作避重參考，由使用者在新 Chat 明確開考。

## 簡潔與可重用

- 架構與個人資料分離：repo 只有規則、合成測試和去個人化驗證；真實學習進度留在使用者對話／交接。
- 藍圖與紀錄都可直接用純文字攜帶，無需 runtime、外部台帳、去重庫、Library 或同步服務。
- 指令自含所以允許必要規則在交接中出現；不要求使用者先閱讀維護者驗收紀錄。只帶已啟用規則與續接必要證據，不搬無限歷史。
- 簡短不等於刪除來源限制、計分保全或等待點。新模式可按需加入，既有模式的有效狀態不能被模板重設。

## 驗收與停止維護

[驗證紀錄](VALIDATION.md)分清靜態檢查、人工合成案例、實際模型互動及真人成效。只有來源可讀與文件規則通過，不能宣稱模型每輪會遵守或學習有效。授權範圍見 [NOTICE](../NOTICE.md)；驗證通過不代表真人學習成效已證。

維護採「設定可觀察驗收→小幅修改→測試→獨立審查→只修缺陷→核對」。沒有已知內容／入口／驗收阻斷時停止修正；兩輪無改善則保留缺陷與續作摘要，不無限美化。
