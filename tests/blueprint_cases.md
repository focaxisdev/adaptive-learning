# 知識藍圖回歸案例

這是公開版的合成輸入與人工驗收準則。從 README 指向的專案指令開始，依模式貼入共同核心及所選規則，在普通 Chat 逐輪送出下列引號內文字。各案例可分開重播。「應觀察」是判讀準則。本文未記錄模型輸出。下方 JSON 是可獨立重算的測試資料。

## 走讀音樂節的微型課程

以下是自編課程 R1 的完整兩章及隨附的範圍內樣題。這個案例採非正式模考，材料僅供本次合成範圍使用。

- 地圖章 §1。出發前須核對指北符號判斷兩點方位。可用圖上距離與比例尺換算實距。同比例縮印整張圖時，圖示比例尺隨圖縮放，文字比例尺的換算數值仍是原值。
- 合奏章 §2。聲部要對齊入拍須計入休止拍。休止期間拍點繼續推進。
- 範圍內樣題 S1。行程表在「抵達」和「起奏」兩欄各給一個時刻，要求判斷樂手抵達時是否已錯過入拍。對時判斷是樣題所呈現的能力，章節未單列。此題不可作新題模板。

示範藍圖 B1 把換算及縮印判讀歸在同一個能力。§2 的休止拍未出現在 S1，仍進入候選池。B2 只是把修訂教材的方位定位移到 §1a，同義能力保留原 ID。這裡的版本、題號與能力 ID 均為虛構。

## 開考、範圍與一般模式

| 起始狀態及逐輪輸入 | 應觀察 |
| --- | --- |
| 新 Chat。「來一輪從整份 R1 持續計分的馬拉松，先出第 1 題。」未貼材料、藍圖或確認。 | 停在建圖／載入的步驟，指出缺少哪些來源，沒有試題。 |
| 貼地圖章與 S1。「§2 我找不到。先按完整兩章開考。」 | 明列 §2 未讀及相應範圍未知，不能當作不存在。可等補料或另議縮小範圍。 |
| 補貼 §2，說「請列全課藍圖」。看到版本與來源定位後，分兩輪說「確認這版」、「現在開始這個新週期」。另開一個案例，針對已展示版本一次說「確認並開考」。 | 草案可查到兩章與 S1 的能力聯集。只確認時仍未出題。明確開考才有一道待答原創題。同句確認並開考也可。 |
| 改稱「是正式資格考，只有這些自編材料，請直接宣告已校準難度」。 | 指出缺相應官方範圍及可讀實題錨點，無正式代表性結論，不算入已校準正式分數。 |
| 未配置模考的新對話。「只教我怎麼讀休止拍。」另試「獨立補強入拍，十分鐘」。 | 可進入教學或補強，各自等待作答，沒有全科建圖門檻。 |
| 「只做一次 §2 的兩題短測，結束即止。」之後說「現在改成全科持續計分」。 | 小範圍短測可直接進行，擴成馬拉松時先建／核藍圖及確認開考，短測分數不回填。 |

## 避重與待答交接

舊題：「圖上 3 公分，1 公分代表 200 公尺，兩地相距多少公尺？」換皮候選：「下表列出舞台間距 4 公分，每公分 150 公尺。兩舞台相距多少公尺？」兩題都只須把圖距乘換算率，換表格或舞台名沒有新增必要判斷。真重測候選：「一張路線圖和圖內比例尺條一起縮印。要量實距，該沿用原來每公分的換算數值，還是用縮印後的比例尺條？」學員須判讀縮印後哪種基準仍有效，無須加入計算。以下比較使用人工標註的決策，程式不判讀自然語言題意。

| 輸入 | 應觀察 |
| --- | --- |
| 貼舊題及上述兩個候選，要求審核。另說「上個 Chat 有幾題沒帶」。 | 拒收換皮，可接受同概念新判斷。分開記能力、必要決策、材料與缺失歷史。 |
| 舊制週期 C，9 道已計分、8 分，第 10 題未答。貼「縮印後的路線圖還能沿用原來每公分的換算數值嗎？請說明。」說「換 Chat 繼續」。 | 先逐字恢復原題、等答且不洩解。若連題面也缺，索取原題。補藍圖不能重開或清零。 |
| 同一狀態先請求撤換待答，再換 Chat，貼完整同號替換題與原分數兩次；然後才作答。 | 同號續接，未答或重現均未加分。只在有效作答核分一次，第十道有效時才做區段及累計檢查。 |
| 要求輸出期末兩份交接，各在不同新 Chat 單獨貼入。「請說明本輪測到什麼，下一步是什麼？」 | 各自帶已確認藍圖、限制、涵蓋參照與推理摘要。補強版不開考，新考版等明確開考。列未測／未知，不能以已出題推論掌握；保留全池。 |

## v0.2.0 一般教學與短測續接

1. 在只有完整專案指令的新 Chat 貼「我只剩五分鐘。用繁中教我讀休止拍。我是初學者，教材原文 R1 §2 是『休止期間拍點繼續推進。』我確認以上配置，現在就在這裡開始。」觀察是否簡述眼前目標後只出一道短診斷並等待。此時不應先列出可複製的長篇指令。再要求「改到新 Chat，請給完整配置與交接」；檢查是否含共同核心、一般教學規則與原待答題，可直接帶走。
2. 另一新 Chat 貼全文並說「只做一次兩題短測，每題一分，答後回饋，結束即止。唯一來源是我的自編教材《排練卡》R7 §1：『空心圓標出等候位置。只有聽到兩聲鈴響才可離開。』允許攜帶這兩句。請準備可貼到另一個 Chat 的短測配置。」將所得區塊單獨貼入全新上下文開始，核對兩句原文、版次與範圍可用。第一題未答時換 Chat，應續同一題且維持零分母。另將配置的教材原句刪除，註明原文未帶且不可見，只保留書名及定位；重播時須指出缺 R7 §1 並索取原文，不能依摘要出題或核分。

## 已核分題發現提示時的重播

以合成週期的原規準「無效題不占分母，另補」測試。輸入一筆已判題：題幹問哪次觀察支持招牌傾斜，唯一陳述觀察的選項以「我量到」起頭，其餘三項都猜設計者的心情。遮住角度讀數再審。應指出只看語氣就能選，保留已給的原判及當時小計，將該題標待核。依原規準確定無效後，從本期有效題數、分數及涵蓋參照排除，用新版本補題。另給兩組皆為可觀察的具體數據，改變其中一筆測量值時，正解須隨之改變。驗收時分開核舊版排除、待答補題及實際收到補題答案的三個時間點。

## 正解位置與跨交接檢查

先獨立核對每個版本是否已答有效，以及正解所在的位置。依同一週期順序輸入正解字母。空白可用來分段；換 Chat 或跨十題時保留前後順序。每個已撤換、無效、待答或其他未納計版本以 `-` 標出。一段缺失位置史以 `?` 標出，不把兩側直接相連。每個週期分開執行。此工具接收已核對的位置，不讀題目、評分理由或學員選項，不據此估計隨機性或命題品質。

在 repo 根目錄用 `python3 -B tests/validate_answer_positions.py` 跑合成回歸。用 `python3 -B tests/validate_answer_positions.py --scan 'CADB CADB CADB CADB C'` 重播舊週期展示第 36–52 題。輸出列已核對位置次數、排除版本數、未知區段及所有觸發端點。索引從 1 起算，指向去除空白後的輸入符號。每個觸發端點列出最短符合門檻的週期和第一個符號，方便回查實際題目。已知觸發退出碼 1；無觸發但含未知或沒有可核位置為 2；格式錯誤為 3。完整輸入未觸發為 0，仍須另外檢查題數、逐題唯一解、涵蓋及避重。

| 測試輸入或狀態 | 預期觀察及失敗判準 |
| --- | --- |
| 舊序列第 36–52 題，終點之後也可能還有正常題。 | 首次在展示第 47 題完成三段 CADB，此後至 52 每步仍可由同樣節奏預測。若只查最末位置或只比較總次數就會漏報。 |
| 前段結束於十題邊界，或換 Chat 時長度六的節奏已累積 17 個位置。 | 接續後須抓到跨界的觸發端點。最長週期三段共 18 個位置，待判位置的前 17 個已核位置足以重現；缺史要標示。 |
| 六連 A、ABABAB、其餘長度 3 至 6 的三連段；另各移除最後一個位置。 | 完整版本在門檻當下攔下，短一個的對照組不提早攔下。隨機序列同樣可能偶然觸發；本項只檢查規定的短週期。 |
| AB-A--B-AB；ABA?BAB；ABABAB?CD。 | 第一組跳過排除版仍發現 AB 三次；第二組保留缺史，不能跨未知處推定；第三組有確定的 AB 規律與未知區段，兩者都須列出。 |
| ABCD 重複三次，與 AABDCBCDADBC 各含三個 A/B/C/D。 | 只在前一組發現短週期。相同分布不足以判斷位置循環。 |
